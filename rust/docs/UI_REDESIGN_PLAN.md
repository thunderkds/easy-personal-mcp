## Linux constraint on the popover (G7)

On Linux, Tauri v2 tray icons use AppIndicator: tray click events do not fire, and only a native menu can open. The
HTML popover in `TrayPopover.dc.html` cannot open on click on Ubuntu/GNOME. Default plan: build G7 as a **native tray
menu** with the same rows in the same order (status rows as disabled items, then Open dashboard, Run ingest now, Pause
alerts for 1 hour, Quit). The dot colours and tooltip stay as designed. The HTML popover stays an option for macOS and
Windows later.
