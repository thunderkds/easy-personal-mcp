## What this means for a live dashboard

* None of the three endpoints is live. The best case is the 1 h lag of the Claude Code analytics
  endpoint; the usage and cost endpoints refresh within 4 h and may take up to 24 h. The live
  target of this spike is under 2 s, so E5 cannot feed it.
* All three endpoints need an Admin API key, which exists only for a Console organization. The
  owner has no such key, so they are out of reach for this project today.
* Claude Code analytics counts API usage only. It does not count subscription (Pro / Max) usage.
* Pro / Max has no usage API in the docs. The only plan figures are on screen in `/usage`. The
  spike found no plan-quota number in any file it stored (see `REPORT.md`, Account usage findings).
